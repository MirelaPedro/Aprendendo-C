# Aprendendo C
Este é um repositório criado para trabalhar o entendimento na linguagem c de um modo mais prático, utilizando do "fazer" para aprender.
Por ter fins de aprendizagem prática e exercício do conhecimento, os projetos serão pequenos e simples, sem contar com uma interface muito detalhada ou um banco de dados, focando apenas na lógica de programação e na linguagem c.

## Projetos
1. Usuários e senhas: um programa que cria um login automaticamente a partir do nome completo do usuário e salva com a respectiva senha. Contendo requisitos para criar uma senha segura.
O sistema não possui um banco de dados, logos os dados serão salvos em dicionários e conferidos nestes, sendo feito a verificação para não repetir usuários quando houver algum login já cadastrado. 

## Do desenvolvimento
Os projetos estão sendo desenvolvidos no vscode, sendo compilados pelo gcc e executados diretamente no terminal do sistema operacional Linux.
